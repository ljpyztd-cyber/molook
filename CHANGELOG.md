# Changelog / 版本记录

## 1.1.1 — 2026-10-15

- Adopt the name **Molook (分子窗)** across the UI, exports, docs, demo and release package. / 界面、导出、文档、演示及发布包统一命名为 **Molook（分子窗）**。
- Rename the public repository to `molook` and update bilingual deployment prompts. / 公开仓库改名为 `molook`，同步中英文部署提示词。
- Keep the existing data-format identifiers and independent camera behavior. / 保持既有数据格式标识和默认独立相机行为。

## 1.1.0 — 2026-10-15

- Independent rotation and zoom by default; linked cameras are opt-in. / 默认独立旋转与缩放，联动改为主动开启。
- UTF-8 command output preserves non-ASCII paths on Windows. / 命令输出统一 UTF-8，保留 Windows 中文等非 ASCII 路径。
- Standalone public distribution with no external skill dependency or private project data. / 独立公开发行，无外部 skill 依赖和私有项目数据。
- English/Chinese README and copy-ready agent deployment prompts. / 中英文说明与可复制的 agent 部署提示词。
- MIT application license; third-party notices retained. / 应用采用 MIT，第三方声明完整保留。
- Explicit release file list, SHA256 manifest, reproducible synthetic examples, and Windows/Ubuntu test workflow. / 明确发布清单、SHA256、可再生合成示例及跨平台测试流程。

## 1.0.0 — 2026-10-04

Initial standalone local handoff: offline renderer, strict structure readers, geometry measurements, view snapshots and high-resolution exports. / 初版独立本地工具：离线渲染、严格格式读取、几何测量、视图保存与高清导出。
